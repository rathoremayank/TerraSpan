Frequently Asked Questions

What is TerraSpan?

TerraSpan is a production-grade Terraform project for managing infrastructure across AWS, Azure, and Google Cloud Platform with a unified, modular architecture.

Is TerraSpan free to use?

Yes! TerraSpan is open source and licensed under Apache 2.0. You only pay for the cloud resources you provision.

How do I get started?

Check our documentation for a quick start guide. You'll need Terraform and cloud credentials to begin.

Can I use TerraSpan in production?

Absolutely! TerraSpan is designed for production-grade infrastructure with built-in security, monitoring, and best practices.

How do I contribute?

Check the CONTRIBUTING.md file in the repository for guidelines on submitting issues, feature requests, and pull requests.

What cloud providers are supported?

TerraSpan supports AWS, Microsoft Azure, and Google Cloud Platform with first-class support for each.
