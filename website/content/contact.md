## Contributing

Interested in contributing? Check our [Contributing Guide](/contributing/).

## Feature Requests

Have an idea for a new feature? Please:
1. Check existing [issues](https://github.com/your-org/terraspan/issues)
2. Start a [discussion](https://github.com/your-org/terraspan/discussions)
3. Submit a feature request in [issues](https://github.com/your-org/terraspan/issues/new)

## Security Concerns

Found a security vulnerability? Please:
1. **DO NOT** open a public issue
2. Email security@terraspan.dev with details
3. Include steps to reproduce if possible

We take security seriously and appreciate responsibly disclosed vulnerabilities.
